# Runbooks

Operational how-tos, one file per procedure. Owned by whoever changes the
procedure — update the runbook in the same PR. See AGENTS.md for what does and
doesn't belong here.

Planned (authored by the issue that creates the procedure):

- `local-dev.md` — build & preview the site; run the app locally (#5, #2)
- `netlify.md` — Netlify site setup, base dir, env vars (#9)
- `deploy.md` — how each half deploys, cutover and rollback (#7)
- `routing.md` — URL structure, redirects, the gsffc.github.io redirect (#7)
- `media.md` — converting and adding media per the asset policy (#4)
