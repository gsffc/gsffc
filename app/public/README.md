# public/

Static assets served directly by Netlify's CDN (they never hit the function).

- `ui/` (and the root `favicon.png` once present) are **generated by
  `npm run ui:build` at the repo root** from `ui/` sources — never edit the
  copies here; CI fails on stale or missing outputs.
- Media rules still apply (AGENTS.md hard rule 1): no GIFs, videos as WebM
  ≤640px/≤2MB, photos as JPG ≤1600px/≤400KB, PNG graphics-only. Check with
  `npm run check:assets` before pushing.
